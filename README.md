# Radar GRC - Sistema de Governança, Risco e Compliance

Sistema completo de Governança, Risco e Compliance (GRC) com foco em LGPD e GDPR.

## 🚀 Funcionalidades
- Dashboard com métricas e gráficos
- Gestão de projetos e riscos
- LGPD & GDPR compliance
- Frameworks ISO (27001, 27002, 27017, 27701, 31000, 37001, 37301)
- IA integrada para classificação automática
- Autenticação com 2 fatores

## 🚀 Deploy
- **Vercel**: Importe o repositório em vercel.com
- **Netlify**: Importe em netlify.com (alternativa rápida)
- **GitHub Pages**: Configure em Settings → Pages
